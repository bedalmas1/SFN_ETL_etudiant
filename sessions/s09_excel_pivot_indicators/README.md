# Séquence 9 — Construire des indicateurs sous Excel

Séance qui applique avec Excel les réflexes déjà survolés : un indicateur compresse toujours la réalité, et l'outil n'exécute que ce qu'on lui demande. Le jeu de données est volontairement plus riche que celui des séquences précédentes : sept zones, quatre grandeurs physiques (température, humidité, tension batterie, qualité de signal LoRa), trois jours de mesures.

## Question directrice

**À la fin, les étudiants doivent décider quelles zones de la base méritent une vérification prioritaire une fois les indicateurs correctement construits sous Excel, et lesquelles un simple filtre unique à 35 °C aurait manquées.**
